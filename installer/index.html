🕷 SpiderBridge

Spider Farmer GGS controller ⇄ Home Assistant. Everything the app can do, 1:1 in Home Assistant — no app, no cloud, installation and operation entirely without them.

1 · Flash the firmware

The firmware targets ESP32-WROOM-32 (4 MB) — developed and tested with this board.

  1. Plug the ESP32 into this computer with a USB data cable (a charge-only cable shows no port).
  2. Click Connect & flash. Chrome opens a window listing serial ports — pick the ESP32 (CP210x, CH340 or USB JTAG/serial) and press Connect.
  3. In the installer dialog press Install SpiderBridge, tick Erase device for a first install, and confirm. Flashing takes about a minute — keep this tab open.
This browser cannot flash over USB. Open this page in Google Chrome or Microsoft Edge on a desktop computer (Firefox, Safari and mobile browsers have no Web Serial). Flashing needs a secure page. Open https://matthias1232.github.io/spider-farmer-homeassistant/installer/.
  • No port in the list? Hold BOOT on the board while clicking Connect, and try another cable or USB port.
  • On Windows the CP210x / CH340 driver may be needed (CP210x, CH340).
  • Close other programs that hold the port (Arduino IDE, serial monitors, other browser tabs).

The installer always uses the newest build of this repository (manifest). Alternatively join the hotspot SpiderBridge (password 12345678, http://192.168.10.1) and configure Wi-Fi manually.

2 · Send Wi-Fi credentials (during installation)

Immediately after flashing, the ESP32 stays in provisioning mode for 5 minutes. Keep this tab open, enter your home Wi-Fi below and click Send Wi-Fi to device — the credentials are sent to the ESP32 over the serial port (Improv Serial, no cables swapped, no browser extensions). Chrome opens the port list again: select the same ESP32.

Use Google Chrome or Microsoft Edge on a desktop computer. This needs an HTTPS page.

If the port disappears after flashing, close and reopen it — the Improv dialog needs the serial port itself. Without this step the bridge creates its own hotspot (SpiderBridge, password 12345678) and you can configure Wi-Fi at http://192.168.10.1.

3 · What happens next

  1. The bridge joins your network — open its web interface (hostname spiderbridge.local or its IP from your router).
  2. Enter your MQTT broker (Settings → MQTT).
  3. Pair the GGS controller over Bluetooth (Control → Bluetooth scan, or the Pair Bluetooth button in Home Assistant).
  4. Home Assistant discovers 183 entities automatically (153 per controller, 30 on the bridge) — done. No app, no cloud.
