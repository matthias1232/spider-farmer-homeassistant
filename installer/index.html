🕷 SpiderBridge

Spider Farmer GGS controller ⇄ Home Assistant. Everything the app can do, 1:1 in Home Assistant — no app, no cloud, installation and operation entirely without them.

1 · Flash the firmware & set up the board

Developed and tested with this ESP32 board.

Auto-detect reads the chip after you connect and installs the matching build. Pick a module only if you want to force one.

Quick Connect does it all in one dialog: joins your home Wi-Fi, creates a new random password for the bridge's hotspot and can connect your GGS controller over Bluetooth.

Already running SpiderBridge? Use the second button: nothing is flashed, the board is just restarted and configured. This works on every SpiderBridge with current firmware, new or in use: its USB console never switches off, and a board that does not answer is explained (older firmware, other firmware, silent) with a way forward.

Or step by step / manage a board that is already set up (IP addresses, single Wi-Fi or password changes, console):

  1. Plug the board into this computer with a USB data cable (a charge-only cable shows no port).
  2. Click Open installer & device tools. Chrome opens a window listing serial ports — pick the board (CP210x, CH340 or USB JTAG/serial) and press Connect.
  3. The window then offers: Install SpiderBridge, IP addresses & status, Send Wi-Fi to device, Connect Wi-Fi & randomize SpiderBridge Wi-Fi password, Randomize SpiderBridge Wi-Fi password and Logs & Console.
This browser cannot flash over USB. Open this page in Google Chrome or Microsoft Edge on a desktop computer (Firefox, Safari and mobile browsers have no Web Serial). Flashing needs a secure page. Open https://matthias1232.github.io/spider-farmer-homeassistant/installer/.
  • No port in the list? Try another USB cable (it must carry data) or another USB port.
  • Install fails with Failed to initialize? Many boards cannot enter download mode on their own: hold the BOOT button while you press Install (or Start in Quick Connect) and release it when the progress bar starts.
  • On Windows the CP210x / CH340 driver may be needed (CP210x, CH340).
  • Close other programs that hold the port (Arduino IDE, serial monitors, other browser tabs).

The installer always uses the newest build of this repository (manifest). Alternatively join the hotspot SpiderBridge (password 12345678, http://192.168.10.1) and configure Wi-Fi manually.

2 · Wi-Fi without Quick Connect

The ESP32 accepts Wi-Fi settings over USB at any time, also after a restart or a crash: its USB console never switches off. Click Send Wi-Fi to device here, or use the same entry in the installer window (it also offers Connect Wi-Fi & randomize SpiderBridge Wi-Fi password, IP addresses & status, Health & restarts and Restart the board). Chrome opens the port list again: select the same ESP32.

Use Google Chrome or Microsoft Edge on a desktop computer. This needs an HTTPS page.

If the port disappears after flashing, close and reopen it — the Improv dialog needs the serial port itself. Without this step the bridge creates its own hotspot (SpiderBridge, password 12345678) and you can configure Wi-Fi at http://192.168.10.1.

3 · Live console

Shows what the board prints, and keeps showing it: after a flash, a restart, a crash or when you unplug the cable and plug it back in, the console reconnects by itself. Click Connect console once and choose the port; Chrome remembers it. While the installer window or Quick Connect uses the port, the console steps aside and comes back afterwards.

Only one program can use the serial port at a time. If the console says busy, close other tabs, the Arduino IDE or serial monitors.

4 · What happens next

  1. The bridge joins your network — open its web interface (hostname spiderbridge.local or its IP from your router).
  2. Enter your MQTT broker (Settings → MQTT).
  3. Pair the GGS controller over Bluetooth (Control → Bluetooth scan, or the Pair Bluetooth button in Home Assistant).
  4. Home Assistant discovers 183 entities automatically (153 per controller, 30 on the bridge) — done. No app, no cloud.
